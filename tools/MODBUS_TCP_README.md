# Modbus TCP пельменеварки: карта версии 2

KC868-A16, Ethernet LAN8720, IP `192.168.1.240/24`, порт `502`, шлюз `192.168.1.1`. Веб-интерфейс и Wi-Fi AP `dumplings` сохранены. Карта несовместима со старой; прошивку и Python-тестер обновлять одновременно.

Сетевые параметры меняются в веб-интерфейсе: DHCP либо статический IP, маска, шлюз и DNS. Кнопка «Сохранить и применить» записывает настройки в NVS ESP32 и через секунду перенастраивает Ethernet без перезапуска прошивки. По умолчанию используется статический `192.168.1.240/24`; изменения сохраняются после перезагрузки. При смене адреса переподключите Modbus-клиент к новому IP; Wi-Fi AP `dumplings` остаётся доступной для исправления настроек. В Python-тестере IP нужно изменить вручную, если он отличается от адреса по умолчанию.

Номер `40001` соответствует адресу `0` (Holding, FC03/06), номер `30001` — адресу `0` (Input, FC04). Пробелы в карте не читаются как нули. FC16 (множественная запись) отклоняется исключением `03`; записывайте по одному регистру. Недопустимая команда, значение, запись RO-регистра или состояние не «готов» дают Modbus-исключение `03`. Неизвестный адрес — `02`. Сервисный результат `40017` оставлен для совместимости с прежней диагностикой.

## Holding: команды и настройки

| Номер | Адрес | Доступ | Назначение |
|---|---:|---|---|
| 40001 | 0 | RW | `Stat_Mode`: `1` готов, `11..13` опустить привод 1..3, `14..16` поднять с встряхиванием 1..3, `19` завершено |
| 40002 | 1 | RO | `Stat_Error`: `0` — ошибок нет |
| 40003–40006 | 2–5 | запрещён | `Man_Control`: чтение и запись → исключение `03` |
| 40007 | 6 | запрещён | Резерв ручного управления: исключение `03` |
| 40008 | 7 | RW | Время опускания, мс |
| 40009 | 8 | RW | Время полного подъёма, мс |
| 40010 | 9 | RW | Подъём до встряхивания, мс |
| 40011 | 10 | RW | Длительность шага встряхивания вверх, мс |
| 40012 | 11 | RW | Длительность шага встряхивания вниз, мс |
| 40013 | 12 | RW | Количество циклов встряхивания, `0..100` |
| 40014 | 13 | RW | Краны: бит 0 залив, бит 1 слив; `1` = закрыт/реле включено |
| 40015 | 14 | RW | ТЭН: `0` выключен, `1` включён |
| 40016 | 15 | RW | Сервисная команда: `4` сохранить тайминги в NVS; `5` поднять выбранный привод без встряхивания |
| 40017 | 16 | RO | Результат сервисной команды: `0` OK, `1` неизвестная, `2` занят, `3` неверный параметр |
| 40018 | 17 | RO | Версия карты: `2` |
| 40019 | 18 | RW | Номер привода `1..3` для сервисной команды `5` |

Команды `11..16` принимаются только из `Stat_Mode = 1`, когда никакой привод не движется. `20` (ручной режим), `30` (аварийная остановка), `99` и запись `1/19` отклоняются исключением `03`. STOP не реализован. После завершения движения `19` показывается 2,5 секунды, затем `1`. При включении питания все приводы поднимаются без встряхивания; пока они движутся, состояние отражает подъём. Положение определяется только по времени.

Тайминги применяются в RAM при остановленных приводах; `40016 = 4` сохраняет их в NVS. Начальные значения: `3500, 3500, 1750, 250, 250, 8`; время до встряхивания не может превышать время полного подъёма. Включение ТЭНа (`40015 = 1`) разрешено только при достаточном уровне воды и закрытых кранах. Если уровень пропал или кран открылся, ТЭН автоматически выключается.

## Input: телеметрия

| Номер | Адрес | Значение |
|---|---:|---|
| 30001 | 0 | Время с запуска ESP32, **целые часы в одном uint16**; насыщение на 65535 |
| 30021–30026 | 20–25 | Виртуальные концевики `1..6`, `0/1` |
| 30051–30066 | 50–65 | Команды реле `1..16`, `0/1` |
| 30071 | 70 | Температура DS18B20, °C ×10, int16; `0x8000` = нет данных |
| 30072 | 71 | Число найденных Dallas-датчиков |
| 30073 | 72 | Поплавок: `1` вода на нужном уровне, `0` недостаточно |
| 30074 | 73 | Состояние кранов, биты как у `40014` |
| 30075 | 74 | Состояние ТЭНа, `0/1` |
| 30076 | 75 | Глобальный статус: бит 0 любой привод занят; бит 1 нагрев разрешён; бит 2 нагрев заблокирован |
| 30077 | 76 | `FillStatus`: `0` открыт, `1` закрыт |
| 30078 | 77 | `DrainStatus`: `0` открыт, `1` закрыт |
| 30079 | 78 | `HeaterStatus`: `0` выключен, включение разрешено; `1` включён; `2` выключен, включение заблокировано |
| 30081–30085 | 80–84 | Привод 1: статус, этап, направление, оставшиеся мс, положение |
| 30086–30090 | 85–89 | То же, привод 2 |
| 30091–30095 | 90–94 | То же, привод 3 |

Виртуальные концевики: `1/2` верх/низ привода 1, `3/4` верх/низ привода 2, `5/6` верх/низ привода 3. Это **не физическая обратная связь**: статус вычисляется из завершённого таймерного движения. Поэтому ошибки `2X0/2X1` из исходной таблицы обнаружить невозможно; `40002` остаётся `0`, состояние `99` не формируется. Наличие `1` не гарантирует фактического положения емкости. Нельзя считать эту телеметрию защитой от заклинивания или перелива.

`FillStatus` и `DrainStatus` показывают команду сервокрану, а не подтверждение его положения: `1` соответствует включённому реле закрытия. `HeaterStatus = 2` означает, что сейчас не выполнена блокировка по уровню воды или закрытию обоих кранов; это не сохранённая авария и не признак неисправности ТЭНа. Существующие `30074/30075` оставлены без изменений для совместимости.

Статус привода: бит 0 занят, бит 1 завершён, бит 2 верх, бит 3 низ, бит 4 реле вверх, бит 5 реле вниз. Этап: `0` ожидание, `1` опускание, `2` начальный подъём, `3/4` встряхивание вверх/вниз, `5` окончательный подъём, `6` завершён. Направление: `0` стоп, `1` вверх, `2` вниз. Положение: `0` неизвестно, `1` верх, `2` низ. Выходы реле — команды, не измерение состояния контактов.

Реле `1/2`, `3/4`, `5/6` управляют тремя приводами; `9` — залив, `10` — слив, `11..13` — три контактора ТЭНа. Выходы PCF8574 `0x24/0x25` активны низким уровнем. Поплавок — PCF8574 `0x22`, физический P0 (бит P7 из-за обратной разводки), замыкание на землю означает достаточный уровень. DS18B20 подключён к GPIO32.

## Python-тестер

Установить `pymodbus`: `pip install pymodbus`. Запуск: `python tools/modbus_tcp_tester.py`. IP по умолчанию совпадает с прошивкой. Для диагностики TCP/Modbus включите `Trace`; веб-интерфейс и USB-монитор на `115200` показывают состояние Ethernet.
